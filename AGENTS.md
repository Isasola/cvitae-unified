# CVitae repository instructions

Before substantial CVitae work, agents must read, in this order:

1. `AGENTS.md`
2. `WORKING_PRINCIPLES.md`
3. `docs/GRAND_CHECKPOINT.md`

The Grand Checkpoint defines the CURRENT ITEM and its scope. Closed items
must not be re-audited without concrete regression evidence. If instructions
conflict, an explicit current user instruction wins; then the Grand
Checkpoint/current item; then AGENTS.md and WORKING_PRINCIPLES.md technical
operating rules.

Before any scraper/source, opportunity-ingestion, source-policy, geo or
maintenance task, read `skills/cvitae-scrapers/SKILL.md` and
`skills/cvitae-scrapers/references/operational-maintenance.md`. They are the
authoritative shared Codex/Claude source contract.

For source identity use the core resolver: canonical source, emitted source
and source family are distinct. Never guess aliases. AUTO requires certified
maintenance; a confirmed live observation may be audited as RESTORE but cannot
directly republish, rematch or reindex an opportunity.
