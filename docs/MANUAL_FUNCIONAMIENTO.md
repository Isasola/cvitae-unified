## PLANTILLA PARA AGREGAR FEATURES VERIFICADAS

```markdown
### ✅ [Nombre del Feature] - Verificado [Fecha]

**Qué hace:**
- Descripción concisa en 2-3 líneas

**Cómo funciona:**
1. Paso 1 del flujo
2. Paso 2 del flujo
3. Paso 3 del flujo

**Archivos involucrados:**
- `ruta/archivo1.ts:líneas` - Rol/responsabilidad
- `ruta/archivo2.tsx:líneas` - Rol/responsabilidad

**Puntos clave para NO romper:**
- ⚠️ Nunca modificar X sin verificar Y
- ⚠️ Si tocas Z, asegurate de que W sigue funcionando
- ⚠️ Este componente depende de [otro componente/tabla/env var]

**Variables de entorno requeridas:**
- `VAR_NAME` - Descripción de qué hace
- `OTRA_VAR` - Descripción

**Tablas de Supabase involucradas:**
- `tabla_name` (columnas: x, y, z)
- `otra_tabla` (columnas: a, b, c)

**Cómo probar que funciona:**
1. Paso de prueba 1
2. Paso de prueba 2
3. Resultado esperado

**Errores comunes:**
- Error X → Causa Y → Solución Z
- Error A → Causa B → Solución C

**Historial de cambios:**
- 2026-11-19: Implementación inicial (commit abc123)
- 2026-11-20: Verificado funcionando

**Próximas mejoras sugeridas:**
- Idea 1
- Idea 2
```
